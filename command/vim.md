Vim
=====================

> Vim 是 Linux/Unix 下最强大的终端文本编辑器之一。
> 
> ⚠️ **最重要的一句话**：Vim 区分「模式」，不同模式下按键含义完全不同。

* * *

Vim 的四种核心模式
-------------

| 模式                 | 说明              | 进入方式               |
| ------------------ | --------------- | ------------------ |
| **普通模式（Normal）**​  | 默认模式，用于移动、删除、复制 | 启动 Vim 后自动进入       |
| **插入模式（Insert）**​  | 编辑文本            | `i`/ `a`/ `o`      |
| **可视模式（Visual）**​  | 选中文本            | `v`/ `V`/ `Ctrl+v` |
| **命令模式（Command）**​ | 执行保存、退出等操作      | `:`                |

👉 **Esc**：回到普通模式（最常用）

* * *

启动与退出
-------

### 1️⃣ 启动 Vim

    vim              # 直接启动
    vim file.txt     # 打开文件
    vim +10 file.txt # 打开并跳到第 10 行

### 2️⃣ 保存与退出（命令模式）

| 命令           | 说明          |
| ------------ | ----------- |
| `:w`         | 保存          |
| `:q`         | 退出          |
| `:wq`/ `:x`  | 保存并退出       |
| `:q!`        | 强制退出（不保存）   |
| `:w newfile` | 另存为新文件      |
| `ZZ`         | 保存并退出（普通模式） |

* * *

光标移动（普通模式）
------------

### 基础移动

| 按键        | 说明        |
| --------- | --------- |
| `h j k l` | ← ↓ ↑ →   |
| `0`       | 行首        |
| `^`       | 行首第一个非空字符 |
| `$`       | 行尾        |
| `gg`      | 文件开头      |
| `G`       | 文件末尾      |
| `:n`      | 跳转到第 n 行  |

### 单词移动

| 按键  | 说明      |
| --- | ------- |
| `w` | 下一个单词开头 |
| `b` | 上一个单词开头 |
| `e` | 单词结尾    |

* * *

编辑操作（普通模式）
------------

### 1️⃣ 进入插入模式

| 命令  | 说明      |
| --- | ------- |
| `i` | 当前位置插入  |
| `I` | 行首插入    |
| `a` | 当前字符后插入 |
| `A` | 行尾插入    |
| `o` | 下方新开一行  |
| `O` | 上方新开一行  |

* * *

### 2️⃣ 删除（Delete）

| 命令    | 说明     |
| ----- | ------ |
| `x`   | 删除当前字符 |
| `dd`  | 删除整行   |
| `dw`  | 删除一个单词 |
| `d$`  | 删除到行尾  |
| `d0`  | 删除到行首  |
| `ndd` | 删除 n 行 |

* * *

### 3️⃣ 复制 & 粘贴（Yank / Paste）

| 命令    | 说明     |
| ----- | ------ |
| `yy`  | 复制一行   |
| `yw`  | 复制一个单词 |
| `p`   | 粘贴到光标后 |
| `P`   | 粘贴到光标前 |
| `nyy` | 复制 n 行 |

* * *

### 4️⃣ 撤销 & 重做

| 命令         | 说明      |
| ---------- | ------- |
| `u`        | 撤销      |
| `Ctrl + r` | 重做      |
| `.`        | 重复上一次操作 |

* * *

查找与替换
-------

### 1️⃣ 查找（普通模式）

| 命令      | 说明        |
| ------- | --------- |
| `/word` | 向下查找 word |
| `?word` | 向上查找 word |
| `n`     | 下一个匹配     |
| `N`     | 上一个匹配     |
| `*`     | 查找光标所在单词  |

### 2️⃣ 替换（命令模式）

| 命令                  | 说明      |
| ------------------- | ------- |
| `:%s/old/new/g`     | 全局替换    |
| `:%s/old/new/gc`    | 替换前确认   |
| `:s/old/new/`       | 当前行替换   |
| `:10,20s/old/new/g` | 指定行范围替换 |

* * *

可视模式（选择文本）
------------

| 模式   | 进入         | 说明      |
| ---- | ---------- | ------- |
| 字符可视 | `v`        | 选字符     |
| 行可视  | `V`        | 选整行     |
| 块可视  | `Ctrl + v` | 选列（超好用） |

✅ 选中后可使用：

* `d`删除

* `y`复制

* `I`批量插入（块模式）

* * *

分屏操作
------

| 命令                   | 说明   |
| -------------------- | ---- |
| `:sp file`           | 上下分屏 |
| `:vsp file`          | 左右分屏 |
| `Ctrl + w + w`       | 切换窗口 |
| `Ctrl + w + h/j/k/l` | 方向切换 |

* * *

常用配置（临时）
----------

    :set nu          " 显示行号
    :set nonu        " 关闭行号
    :set hlsearch    " 高亮搜索
    :set incsearch   " 实时搜索
    :set tabstop=4   " Tab 宽度

* * *

新手最常卡住的点 ✅
------------

❌ 无法输入？

→ 按 `i`进入插入模式

❌ 不知道怎么退出？

→ 按 `Esc`→ `:q!`

❌ 误删文件？

→ `u`撤销

❌ 想复制粘贴？

→ `yy`→ `p`
