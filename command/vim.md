vim
===

**vim (Vi IMproved)**​ 是 Linux 和 Unix 系统中最经典、最强大的**全屏文本编辑器**之一。它被广泛应用于服务器配置、代码开发、脚本编写以及系统运维（DevOps）工作中。vim 的核心优势在于**纯键盘操作**、**模式编辑**以及极高的可定制性，熟练使用后能极大提升文本处理效率。
补充说明

----

**vim 命令**​ 不仅仅是一个编辑器，它是一个完整的文本处理环境。与普通的编辑器（如 Notepad）不同，vim 严格区分 **“输入文字”**​ 和 **“编辑操作”**，这种设计使得用户无需鼠标即可完成复杂的文本重构。

vim 的工作流程基于以下核心概念：

* **模态性（Modality）**：不同的模式下，键盘按键的含义完全不同。

* **组合命令（Composability）**：操作（Operator） + 范围（Motion），例如 `d`（删除）+ `w`（一个单词）= `dw`（删除一个单词）。

* **可扩展性**：通过 `.vimrc`和插件系统，可以将其打造成 IDE。

* * *

### 语法

    vim [选项] [文件 ...]
    vim [选项] -
    vim [选项] -t 标签

* * *

### 选项

| 选项             | 说明                                       |
| -------------- | ---------------------------------------- |
| `+[num]`       | 打开文件后，光标定位到第 `num`行。省略 `num`则定位到最后一行。    |
| `+/pattern`    | 打开文件后，光标定位到第一个匹配 `pattern`的行。            |
| `-R`           | **只读模式**。防止误修改文件。                        |
| `-b`           | **二进制模式**。用于编辑二进制文件（如可执行文件、图片）。          |
| `-d`           | **Diff 模式**（同 `vimdiff`）。并排比较两个或多个文件的差异。 |
| `-o[N]`        | 水平分屏打开 N 个窗口（N 可选）。                      |
| `-O[N]`        | 垂直分屏打开 N 个窗口。                            |
| `-p[N]`        | 使用标签页（Tab Page）打开 N 个文件。                 |
| `-u <vimrc>`   | 使用指定的配置文件启动，跳过默认的 `~/.vimrc`。            |
| `-y`           | **Easy Mode**。模拟普通编辑器的行为（尽量少用）。          |
| `-v`           | **Vi Mode**。尽可能兼容 Vi。                    |
| `-g`           | 启动 GUI 版本（gvim）。                         |
| `-c "cmd"`     | 启动后立即执行指定的 vim 命令。                       |
| `-S "session"` | 恢复之前保存的会话文件。                             |

* * *

### 参数

| 参数          | 说明                                         |
| ----------- | ------------------------------------------ |
| `file`      | 要编辑的一个或多个文件名。如果文件不存在，vim 会在保存时创建。          |
| `directory` | 如果参数是目录（如 `vim .`），vim 会启动内置的文件浏览器（Netrw）。 |
| `-`         | 从标准输入（stdin）读取内容进行编辑。                      |

### 实例

#### 1️⃣ 基础文件操作

    # 新建或编辑文件
    vim test.txt
    
    # 打开文件并跳转到第 100 行
    vim +100 test.txt
    
    # 打开文件并直接搜索 "error"
    vim +/error /var/log/syslog
    
    # 以只读方式查看配置文件
    vim -R /etc/fstab

#### 2️⃣ 多文件与分屏

    # 垂直分屏打开两个文件
    vim -O file1.conf file2.conf
    
    # 水平分屏并指定大小
    vim -o3 log1.log log2.log log3.log
    
    # 使用标签页打开项目文件
    vim -p *.py

#### 3️⃣ 文件对比（Diff）

    # 对比新旧配置文件
    vim -d nginx.conf nginx.conf.bak

#### 4️⃣ 高级启动

    # 启动时自动替换所有 foo 为 bar
    vim -c "%s/foo/bar/g" -c "wq" file.txt
    
    # 编辑来自管道的输入
    cat access.log | grep "404" | vim -

### 详细操作指南（核心章节）

vim 的强大在于其操作逻辑，以下是详细的模式与命令说明。

#### 📌 模式详解

| 模式                  | 标识              | 作用                  | 进入方式                         |
| ------------------- | --------------- | ------------------- | ---------------------------- |
| **普通模式 (Normal)**​  | `(Normal)`      | 执行删除、复制、移动等命令（默认模式） | `Esc`                        |
| **插入模式 (Insert)**​  | `-- INSERT --`  | 输入文本                | `i`, `a`, `o`                |
| **可视模式 (Visual)**​  | `-- VISUAL --`  | 选中文本块               | `v`(字符), `V`(行), `Ctrl+v`(块) |
| **命令模式 (Command)**​ | `:`             | 执行保存、退出、搜索等指令       | `:`                          |
| **替换模式 (Replace)**​ | `-- REPLACE --` | 覆盖输入                | `R`                          |

#### 📌 光标移动（普通模式）

**基础移动**
    h       左
    j       下
    k       上
    l       右

**行内移动**
    0       跳至行首（绝对位置）
    ^       跳至行首第一个非空字符
    $       跳至行尾
    g_      跳至行尾最后一个非空字符
    f<char> 跳至当前行下一个指定字符 (如 fx 找 x)
    F<char> 反向查找
    t<char> 跳至指定字符前

**单词移动**
    w       下一个单词开头
    b       上一个单词开头
    e       当前单词结尾
    W/B/E   按空白分隔的大单词

**文件级跳转**
    gg      文件第一行
    G       文件最后一行
    :<num>  跳转到第 num 行
    H       屏幕顶部
    M       屏幕中间
    L       屏幕底部
    Ctrl+f  向下翻页
    Ctrl+b  向上翻页

#### 📌 编辑命令（普通模式）

**删除（Delete / Cut）**
    x       删除光标下字符
    X       删除光标前字符
    dd      删除（剪切）当前行
    dw      删除到下一个单词开头
    d$      删除到行尾
    D       同 d$
    dG      删除到文件末尾
    dgg     删除到文件开头

**复制（Yank）**
    yy      复制当前行
    yw      复制到单词结尾
    y$      复制到行尾
    p       粘贴到光标后
    P       粘贴到光标前

**撤销与重做**
    u       撤销
    Ctrl+r  重做
    .       重复上一次操作

**更改（Change）**
    cw      更改单词（删除并进入插入模式）
    cc      更改整行
    C       更改到行尾
    r       替换单个字符
    R       进入替换模式

#### 📌 搜索与替换（命令模式）

    /pattern    向下搜索 pattern
    ?pattern    向上搜索 pattern
    n           跳转到下一个匹配
    N           跳转到上一个匹配
    
    # 替换语法
    :[range]s/old/new/[flags]
    
    # 示例
    :%s/foo/bar/g        全局替换（所有行）
    :s/foo/bar/g         替换当前行
    :5,10s/foo/bar/g     替换 5-10 行
    :%s/foo/bar/gc       替换前询问确认
    :%s/\t/    /g        将 Tab 替换为空格

#### 📌 窗口与标签页管理

    # 分屏
    :split       水平分割
    :vsplit      垂直分割
    Ctrl+w w     切换窗口
    Ctrl+w q     关闭当前窗口
    Ctrl+w =     平分窗口大小
    
    # 标签页
    :tabnew      新建标签页
    gt           下一个标签页
    gT           上一个标签页

#### 📌 可视模式（批量操作）

1. 按 `Ctrl+v`进入 **块可视模式**。

2. 移动光标选中矩形区域。

3. 按 `I`(大写 i) 进入插入模式。

4. 输入文本（如 `#`注释符）。

5. 按 `Esc`，选中的所有行都会生效。

### 扩展知识

#### `.vimrc`配置示例

    " 基本设置
    set number              " 显示行号
    set relativenumber      " 显示相对行号
    set tabstop=4           " Tab 宽度为 4
    set shiftwidth=4        " 自动缩进宽度为 4
    set expandtab           " 将 Tab 转换为空格
    set autoindent          " 自动缩进
    set smartindent         " 智能缩进
    set wrap                " 自动换行
    set hlsearch            " 高亮搜索结果
    set ignorecase          " 搜索忽略大小写
    set mouse=a             " 启用鼠标支持
    
    " 快捷键映射
    map <C-s> :w<CR>        " Ctrl+s 保存
    imap <C-s> <Esc>:w<CR>a " 插入模式下 Ctrl+s 保存

#### 寄存器（Registers）

vim 拥有多个剪贴板（寄存器）：

* `"0`：最近复制的文本

* `"+`：系统剪贴板（需要 vim 支持 `+clipboard`）

* `"a`-`"z`：命名寄存器

使用：`"ayw`（复制到 a 寄存器），`"ap`（粘贴 a 寄存器）。

### 注意

* **无法退出**：这是最常见的问题。请按 `Esc`确保回到普通模式，然后输入 `:q!`（不保存退出）或 `:wq`（保存退出）。

* **交换文件（Swap Files）**：如果 vim 非正常退出（如断网），再次打开文件时会看到 `.filename.swp`文件提示。通常选择 `(R)`恢复或 `(D)`删除。

* **权限问题**：如果编辑系统文件时没有 `sudo`权限，保存时会报错 `E212`。可以使用 `:w !sudo tee %`强制保存。

* **编码问题**：中文乱码时，尝试在 `.vimrc`中加入 `set encoding=utf-8`。

* **大文件**：vim 不适合直接打开 GB 级别的大日志文件，建议使用 `less`或 `sed`。
