tcpdump
===

tcpdump 是一款常用的**命令行网络抓包分析工具**，可监听网络接口上的流量，捕获并解析数据包，常用于网络故障排查、协议分析、安全审计等场景。
补充说明

----

**tcpdump 命令**​ 用于截取和显示通过网络接口传输的数据包。它支持 **BPF（Berkeley Packet Filter）**​ 语法过滤，可以精确抓取特定主机、端口、协议的数据，并可将结果保存为 `.pcap`文件，供 Wireshark 等工具进一步分析。

> ⚠️ 在大多数系统中，运行 tcpdump 需要 **root 权限**​ 或 `CAP_NET_RAW`/ `CAP_NET_ADMIN`权限。

* * *

### 语法

    tcpdump [选项] [表达式]

* * *

### 选项

    -i <接口>       指定网络接口（如 eth0、ens33、lo）
    -n             不解析主机名（直接显示 IP）
    -nn            不解析主机名和端口名（直接显示数字端口）
    -v             显示详细信息（-vv、-vvv 更详细）
    -c <数量>       只抓取指定数量的数据包后退出
    -w <文件>       将抓包数据写入文件（通常为 .pcap）
    -r <文件>       从文件中读取数据包（配合 -w 使用）
    -s <长度>       设置抓取数据包的长度（默认 262144，-s 0 表示完整）
    -X             以十六进制和 ASCII 同时显示数据
    -e             显示链路层头部（MAC 地址）
    -q             静默模式，输出更简洁
    -A             以 ASCII 方式显示数据（常用于 HTTP）
    -p             不使用混杂模式
    -B <大小>       设置操作系统缓冲区大小（单位 KB）
    -t             不显示时间戳
    -tt            显示完整时间戳

* * *

### 参数（过滤表达式）

tcpdump 的核心是 **过滤表达式**，用于筛选感兴趣的数据包：

| 类型   | 示例                   | 说明      |
| ---- | -------------------- | ------- |
| 主机   | `host 192.168.1.1`   | 抓取指定 IP |
| 网段   | `net 192.168.1.0/24` | 抓取整个网段  |
| 端口   | `port 80`            | 抓取指定端口  |
| 端口范围 | `portrange 20-25`    | 抓取端口范围  |
| 协议   | `tcp`、`udp`、`icmp`   | 指定协议    |
| 方向   | `src`、`dst`          | 源或目的    |
| 组合   | `and`、`or`、`not`     | 逻辑运算    |

✅ 示例组合：
    host 192.168.1.10 and port 443
    tcp and not dst port 22

* * *

### 实例

#### 1️⃣ 查看可用网络接口

    tcpdump -D

#### 2️⃣ 抓取指定网卡流量

    tcpdump -i eth0

#### 3️⃣ 抓取指定主机的所有流量

    tcpdump host 192.168.1.100

#### 4️⃣ 抓取指定端口（如 HTTP）

    tcpdump port 80

#### 5️⃣ 抓取 TCP 且非 SSH 流量

    tcpdump tcp and not port 22

#### 6️⃣ 抓取完整数据包并保存到文件

    tcpdump -i eth0 -s 0 -w capture.pcap

#### 7️⃣ 从文件中读取并分析

    tcpdump -r capture.pcap

#### 8️⃣ 显示 HTTP GET 请求

    tcpdump -A -s 0 'tcp port 80 and (((ip[2:2] - ((ip[0]&0xf)<<2)) - ((tcp[12]&0xf0)>>2)) != 0)'

* * *

### 扩展知识

* `.pcap`文件是 **跨平台标准抓包格式**，可被 Wireshark、tshark 直接打开。

* tcpdump 使用的过滤语法与 **Wireshark BPF 过滤器**​ 基本一致。

* 在高流量环境中，建议：
  
  * 使用 `-c`限制包数
  
  * 使用 `-w`写文件，避免终端刷屏
  
  * 增大缓冲区 `-B`
    
    

* * *

### 注意

* 🔒 抓包可能涉及隐私和安全合规，**仅限授权环境使用**。

* 生产环境慎用 `-A/-X`，可能输出敏感信息（密码、Token）。

* 若未指定 `-i`，tcpdump 通常选择 **系统默认接口**。

* 在云服务器（如 AWS、阿里云）中，部分虚拟网卡可能需要开启 **混杂模式**​ 才能抓包。
